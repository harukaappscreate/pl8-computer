# PL-8 ハードウェア設計仕様書 (Hardware Architecture & ISA Reference)

本ドキュメントは、自作 8 ビット・マイクロコンピュータ `PL-8` のハードウェア構成、メモリマップ、算術論理演算回路（ALU）、入出力回路（MMIO）、および命令セットアーキテクチャ（ISA）の技術リファレンスです。

---

## 1. システム全体構成

PL-8 は 8 ビットデータバス、8 ビットアドレスバス（256 バイト空間）、16 ビット固定長命令ワードを持つ Harvard/Von-Neumann ハイブリッド構造のマイクロコンピュータです。

```
+-----------------------------------------------------------------------+
|                       PL-8 Microcomputer System                       |
|                                                                       |
|  +--------------------+   +-------------------+   +----------------+  |
|  |     PL-8 CPU       |   |  Ripple-Carry ALU |   | 256-byte SRAM  |  |
|  | 8-bit Data Bus     |<--| Full Adder Gates  |-->| $00 - $FF      |  |
|  | PC, SP, R0-R7, Z, C|   | A, B, Carry LEDs  |   | MEM/STK Monitor|  |
|  +--------------------+   +-------------------+   +----------------+  |
|            |                                              |           |
|            +-------------------+--------------------------+           |
|                                | Memory-Mapped I/O (MMIO)             |
|  +-----------------------------+-----------------------------------+  |
|  |                                                                 |  |
|  |  [$F0] Gamepad Latch (Left, Right, Fire)                        |  |
|  |  [$F1] 4x4 Tactile Keypad Latch (0-9, +,-,*,/,=,C)              |  |
|  |  [$F2-$F7] 6-Digit 7-Segment VFD Controller (Phosphor Glow)     |  |
|  |  [$FC] Piezoelectric Sound Latch (Pitch / Frequency)            |  |
|  |  [$FD] Hardware LFSR Random Number Generator                    |  |
|  |  [$FE] CPU Busy / Thinking State Latch                          |  |
|  |                                                                 |  |
|  +-----------------------------------------------------------------+  |
|                                |                                      |
|  +--------------------+   +----+--------------+   +----------------+  |
|  | 64x32 Green LCD    |   | 2-in-1 ROM Slot   |   | Tactile Keypad |  |
|  | 32 Dynamic PCG     |   | [B] Button Swap   |   | 4x4 Matrix     |  |
|  | Tile Engine        |   | CALC-16 / BRICK   |   | Keycap Shadow  |  |
|  +--------------------+   +-------------------+   +----------------+  |
+-----------------------------------------------------------------------+
```

## 2. CPU コア仕様

### 2.1 レジスタ構成
| レジスタ | ビット幅 | 用途 |
| :---: | :---: | :--- |
| **`R0` 〜 `R7`** | 8 bit | 汎用レジスタ（算術演算、データ転送、ポインタ） |
| **`PC`** | 8 bit | プログラムカウンタ（ROM 内の命令アドレス 0..255） |
| **`SP`** | 8 bit | スタックポインタ（SRAM 領域、初期値 `$EF` = 239） |
| **`Z`** | 1 bit | ゼロフラグ（直前の演算結果が 0 のとき 1） |
| **`C`** | 1 bit | キャリーフラグ（加算の繰り上がり、減算のボロー、シフトの溢れ） |

- **レジスタ `R7` の特殊機能**:  
  メモリアクセス命令（`LD`, `ST`）において、参照アドレスに `255`（`$FF`）を指定すると、`R7` レジスタの値をアドレスとする間接参照（ポインタアクセス）として機能します。

### 2.2 スタック機構
スタックはメインメモリ（SRAM）の上位領域を使用します。
- **スタックポインタ (`SP`)**: 初期値 `$EF`。
- **`PSH Rr`**: `M[SP] = Rr` を格納後、`SP` をデクリメント（下位方向へ伸長）。
- **`POP Rr`**: `SP` をインクリメント後、`Rr = M[SP]` を取得。
- **`CALL addr`**: 現在の `PC + 1` をスタックへ退避。
- **`RET`**: スタックから戻り番地を `PC` へ復帰。

### 2.3 可変クロック周波数
1 フレーム（60 fps）あたりに実行する命令数を切り替えることで、クロック速度を制御します：
- **`STEP`**: キー入力（上キー）ごとに 1 命令ずつステップ実行
- **`15Hz`**: 4 フレームに 1 命令実行（低速動作観察用）
- **`240Hz`**: 1 フレームあたり 4 命令実行
- **`4kHz`**: 1 フレームあたり 68 命令実行（標準実行速度）
- **`27kHz`**: 1 フレームあたり 450 命令実行（高速演算モード）

## 3. リップルキャリー加算器 (ALU)

PL-8 の加算、減算、比較演算は、プログラミング言語の算術加算（`+`）演算子を使わず、物理的な半導体論理回路である **1 ビット全加算器（Full Adder）** を 8 段直列接続したリップルキャリー方式で評価されます。

### 3.1 論理回路式
各ビット $i$（$0 \le i \le 7$）における和 $S_i$ およびキャリー出力 $C_{i+1}$：

$$S_i = A_i \oplus B_i \oplus C_i$$

$$C_{i+1} = (A_i \cdot B_i) \mid ((A_i \oplus B_i) \cdot C_i)$$

- 減算命令（`SUB`, `SBC`, `CMP`, `CPI`）は、B 入力の全ビットを反転（1の補数）し、キャリー入力 $C_0$ に $1 - C$ を与えることで加算器と共通の回路で処理します（2の補数減算）。

### 3.2 ALU 入出力インジケーター
画面上部には、加算器の内部状態を可視化する LED アレイが配置されています：
- **`A` 行**: 第 1 オペランドの各ビット値（8 ドット）
- **`B` 行**: 第 2 オペランドの各ビット値（8 ドット）
- **`C` 行**: キャリー伝搬信号（下位から上位へビットが繰り上がっていく経路）

## 4. メモリマップ & I/O 空間 (Memory Map)

メモリ空間は全体で 256 バイト（`$00` 〜 `$FF`）のアドレス空間を持ちます。

```text
$00 ───────+────────────────────────────────────────+
           |                                        |
           | ワークエリア (汎用変数領域)              |
           |                                        |
$EF ───────+────────────────────────────────────────+
           | スタック領域 (初期 SP: $EF, 下位伸長)    |
$F0 ───────+────────────────────────────────────────+
           | [$F0] PAD    ゲームパッド入力 (R)       |
           | [$F1] KEY    4x4 テンキー入力 (R)       |
           | [$F2] SEG0   7セグ VFD 桁 0 (W)         |
           | [$F3] SEG1   7セグ VFD 桁 1 (W)         |
           | [$F4] SEG2   7セグ VFD 桁 2 (W)         |
           | [$F5] SEG3   7セグ VFD 桁 3 (W)         |
           | [$F6] SEG4   7セグ VFD 桁 4 (W)         |
           | [$F7] SEG5   7セグ VFD 桁 5 (W)         |
           | [$F8-$FB]    拡張 I/O 予約領域          |
           | [$FC] SND    圧電サウンダー周波数 (W)   |
           | [$FD] RND    LFSR ハードウェア乱数 (R)  |
           | [$FE] BUSY   演算中ビジー状態 (W)       |
$FF ───────+────────────────────────────────────────+
           | 間接参照ポインタ ([R7] 参照用アドレス)   |
           +────────────────────────────────────────+
```

### 4.1 MMIO レジスタ詳細
| アドレス | 識別名 | アクセス | ビット定義・動作 |
| :---: | :---: | :---: | :--- |
| **`$F0`** | `PAD` | Read | ゲームパッドのボタン状態。<br>・Bit 2 (`4`): 左 (Left / A キー)<br>・Bit 3 (`8`): 右 (Right / D キー)<br>・Bit 4 (`16`): 発射 / アクション (Fire / Z キー) |
| **`$F1`** | `KEY` | Read | 4×4 テンキーの押下キー番号 (0〜15)。<br>キーが押されていない間は直前の入力値を保持。 |
| **`$F2`〜`$F7`**| `SEG0`〜`SEG5` | Write | 6桁 7セグメント VFD 出力（SEG0が最上位桁、SEG5が最下位桁）。<br>・値 0〜9: 数字表示<br>・値 10: マイナス記号 `-`<br>・値 11: エラー表示 `E`<br>・値 15: 消灯（ブランク）<br>・Bit 7 (`$80`): 小数点（ドット）点灯 |
| **`$FC`** | `SND` | Write | 圧電サウンダーの音程ラッチ。<br>・値 1〜15: 設定周波数のトーンを出力（0 で消音）。 |
| **`$FD`** | `RND` | Read | 8 ビット LFSR（線形帰還シフトレジスタ）による疑似乱数取得。 |
| **`$FE`** | `BUSY` | Write | CPU 演算中ステート。<br>書き込みを行うと画面上の演算インジケーターが点灯。 |

## 5. ディスプレイ & グラフィックス

### 5.1 6桁 7セグメント VFD（真空蛍光表示管）
- 真空蛍光管特有のシアン（青緑色）の蛍光グローエフェクトをシミュレート。
- 各セグメントは `A`〜`G` の 7 つの素子から成り、MMIO `$F2`〜`$F7` の値に応じてテーブルデコードされて描画されます。

### 5.2 64×32 グリーン LCD（32 PCG タイル）
Playload の PCG（プログラマブル・キャラクタ・ジェネレータ）上限である **32 枚（$8 \times 8$ ピクセル/枚）** を、$4 \times 8$ のグリッド状に敷き詰め、$64 \times 32$ ドットの連続した VRAM ディスプレイを構成しています。
- **高速矩形描画命令 (`RECT`)**:  
  指定した座標 $(X, Y)$ および幅・高さの矩形ビットマップを VRAM 上にダイレクトに反転・描画します。
- **画面消去命令 (`CLS`)**:  
  PCG パターンバッファを 0 クリアし、画面を消去します。

## 6. 命令セット一覧 (ISA Reference)

すべての命令は **16 ビット（1 ワード = 2 バイト）固定長** です。
- 上位バイト (`Hi`): `(Opcode << 3) | Reg`（命令コード 5 bit ＋ 対象レジスタ 3 bit）
- 下位バイト (`Lo`): `Imm`（8 bit 即値）または `Addr`（8 bit メモリアドレス）

### 命令一覧表
| Opcode | ニーモニック | オペランド | フラグ変化 | 機能説明 |
| :---: | :--- | :--- | :---: | :--- |
| **`0x0`** | `LDI` | `Rr, imm` | - | レジスタ Rr に 8 ビット即値をロードする |
| **`0x1`** | `LD` | `Rr, [addr]` | - | メモリ番地 addr の値を Rr にロードする (addr=255 時は [R7]) |
| **`0x2`** | `ST` | `[addr], Rr` | - | レジスタ Rr の値をメモリ番地 addr に格納する (addr=255 時は [R7]) |
| **`0x3`** | `ADI` | `Rr, imm` | Z, C | レジスタ Rr に即値 imm を加算する (INC/DEC にも使用) |
| **`0x4`** | `CPI` | `Rr, imm` | Z, C | レジスタ Rr と即値 imm を比較し、フラグを更新する |
| **`0x5`** | `ANI` | `Rr, imm` | Z, C | レジスタ Rr と即値 imm のビット論理積を計算する |
| **`0x6`** | ALU 群 | `Rr, Rs` | Z, C | 2 レジスタ間の論理・算術演算（下表参照） |
| **`0x7`** | シフト群 | `Rr, mode` | Z, C | レジスタ Rr のビットシフト・回転（下表参照） |
| **`0x8`** | `JMP` | `addr` | - | 指定アドレス addr へ無条件ジャンプ |
| **`0x9`** | `JZ` | `addr` | - | ゼロフラグ Z が 1 のとき jump |
| **`0xA`** | `JNZ` | `addr` | - | ゼロフラグ Z が 0 のとき jump |
| **`0xB`** | `JC` | `addr` | - | キャリーフラグ C が 1 のとき jump |
| **`0xC`** | `JNC` | `addr` | - | キャリーフラグ C が 0 のとき jump |
| **`0xD`** | `DJNZ` | `Rr, addr` | Z, C | レジスタ Rr を減算し、非ゼロなら addr へジャンプ (高速ループ) |
| **`0xE`** | `CALL` | `addr` | - | 戻りアドレスをスタックに退避し、addr のサブルーチンを呼び出す |
| **`0xF`** | システム群 | 各種 | 各種 | 特殊命令群（下表参照） |

---

### Opcode 0x6: ALU 演算詳細 (`Lo` バイト = `(sub_op << 4) | Rs`)
| sub_op | ニーモニック | 動作 |
| :---: | :--- | :--- |
| **0** | `MOV Rr, Rs` | `Rr = Rs`（フラグ変化なし） |
| **1** | `ADD Rr, Rs` | `Rr = Rr + Rs`（加算） |
| **2** | `ADC Rr, Rs` | `Rr = Rr + Rs + C`（キャリー付き加算） |
| **3** | `SUB Rr, Rs` | `Rr = Rr - Rs`（減算） |
| **4** | `SBC Rr, Rs` | `Rr = Rr - Rs - C`（ボロー付き減算） |
| **5** | `CMP Rr, Rs` | `Rr - Rs`（比較、結果は格納せずフラグのみ更新） |
| **6** | `AND Rr, Rs` | `Rr = Rr & Rs`（ビット論理積） |
| **7** | `XOR Rr, Rs` | `Rr = Rr ^ Rs`（排他的論理和） |
| **8** | `OR Rr, Rs`  | `Rr = Rr | Rs`（ビット論理和） |

---

### Opcode 0x7: シフト・回転詳細 (`Lo` バイト = `mode`)
| mode | ニーモニック | 動作 |
| :---: | :--- | :--- |
| **0** | `SHL Rr` | 左論理シフト（最下位に 0 を挿入、最上位は C へ） |
| **1** | `ROL Rr` | キャリー付き左回転（最下位に直前の C を挿入、最上位は C へ） |
| **2** | `SHR Rr` | 右論理シフト（最上位に 0 を挿入、最下位は C へ） |
| **3** | `ROR Rr` | キャリー付き右回転（最上位に直前の C を挿入、最下位は C へ） |

---

### Opcode 0xF: システム命令詳細
| 命令 | Lo バイト | 動作 |
| :--- | :---: | :--- |
| **`WFI`** | `$00` | 1 フレーム待機（垂直同期 VSYNC 待ち） |
| **`RET`** | `$01` | サブルーチンから復帰（スタックから戻り番地を POP） |
| **`PSH Rr`** | `$02` | レジスタ Rr の値をスタックへプッシュ |
| **`POP Rr`** | `$03` | スタックから値をポップしてレジスタ Rr へ格納 |
| **`CLS`** | `$04` | 画面消去（VRAM / PCG パターンをクリア） |
| **`RECT [param]`** | `$05` | 矩形描画（座標・サイズパラメータに基づく VRAM 反転描画） |
